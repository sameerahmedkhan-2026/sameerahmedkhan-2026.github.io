# questions

1. What accessibility feature should be included in SVG icons?
   ans: The accessibility feature that should be included in SVG icons is the use of descriptive `aria-label` or `title` attributes to provide context for screen readers. This ensures that users with visual impairments can understand the purpose of the icon.
